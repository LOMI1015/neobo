# ADR 0006：应用 UI 组件与编辑菜单

- 状态：已接受（实施及验证见迭代记录）
- 日期：2026-10-23
- 范围：shadcn/ui 接入、统一应用样式、上下文编辑菜单
- 关联：[ADR 0005](0005-canvas-editor.md)、[前端规范](../development.md#前端界面与交互)

## 背景

用户确认使用 shadcn/ui，并将本轮限定为组件环境、统一样式和右键编辑菜单。当前界面存在重复的控件样式和功能说明段落，需要按已确定规范收敛；图表与组件注册不属于本轮。

## 决策

1. 使用 shadcn 4.22.1 官方生成的 Radix + Nova 组件源码，公共控件放在 `apps/web/src/components/ui`。本轮仅引入按钮、输入框、文本域、复选框、右键菜单和下拉菜单；源码按仓库格式检查，保留完整 MIT 许可，不引入演示页。
2. Tailwind CSS 与 Vite 插件固定 4.3.3；Vite、TypeScript 和 Vitest 使用一致的 `@/*` 别名，保留现有开发代理、监听及严格类型设置。依赖通过锁文件安装，不依赖额外安装脚本。
3. 应用外壳和控件消费同一份语义颜色、字体、圆角及间距；场景文字和图形仍由只读绘制器定义，不把 UI 变量写进场景。移除用途、教学及路线图文案，保留操作标签、选择/连接/修订状态、错误和简短的数据丢失风险提示。
4. 图层及画布提供自定义右键菜单，工具栏保留可见的同等操作及“更多操作”入口。右键未选对象时选择该对象；命中已选对象或被已选祖先覆盖的后代时保留选区，空白处也保留选区；菜单显示当前选中数量，明确操作范围。
5. 菜单调用既有编辑回调及历史，不另建命令通道。打开与取消菜单不写场景，拖动时不打开菜单，菜单打开时不新建拖动；视图隐藏或修订改变时关闭菜单，焦点、键盘导航及浮层定位复用 Radix。
6. 常驻 shadcn CLI 引入无修复版本的高危间接依赖 `braces`，不将它加入项目依赖。按官方 eject 方式保留当前控件所需的四个 CSS 状态变体到 `src/shadcn.css`；固定版本 CLI 仅通过 `ui:add` 按需执行，不参与正常安装、构建或 CI。保留组件源码与运行依赖，审计门槛保持不变。

## 依据与代价

- 官方支持既有 Vite 项目，Tailwind Vite 插件的当前依赖声明支持 Vite 8；Radix 和 Lucide 的依赖声明支持 React 19。实际兼容性仍以本仓库的构建、类型、单元和浏览器结果为证据。[Vite 接入](https://ui.shadcn.com/docs/installation/vite)、[Tailwind Vite 插件](https://tailwindcss.com/docs/installation/using-vite)。
- shadcn 支持将公共 CSS 归入项目后移除 CLI。归入项目的样式和组件需要自行 review、维护；添加后续组件时核对新增变体及依赖，不自动覆盖本地修改。[CLI 与 eject](https://ui.shadcn.com/docs/cli#eject)、[漏洞通告](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)。
- Radix 提供上下文菜单的捕获、定位、焦点及键盘能力，不自行实现另一套菜单基础设施。[右键菜单](https://www.radix-ui.com/primitives/docs/components/context-menu)。

## 验收与后续

按实际变更验证菜单命中、多选作用域、原子撤销、取消、焦点返回、隐藏释放、窄屏定位和既有拖动。真实浏览器验收继续放在本地，CI 不新增浏览器安装或回归步骤。图表、组件注册、存储和场景主题仍按路线图后续实施。
