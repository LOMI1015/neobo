# ADR 0009：独立只读播放器与场景预览

- 状态：已接受（实施与本地验收通过）
- 日期：2026-10-23
- 范围：播放器包、编辑器预览、构建边界和资源释放
- 关联：[ADR 0007](0007-component-registry.md)、[ADR 0008](0008-static-bar-chart.md)

## 背景

路线图下一步是编辑器与播放器独立打包，验证只读入口消费当前场景且不携带编辑器代码。现有 `SceneView` 和注册组件已具备只读绘制与生命周期，但仍位于 Web 应用目录；当前没有保存、发布快照或动画内核。

## 决策

1. 新增 `packages/player`，包名 `@neobo/player`，输出独立 ESM JavaScript 与 TypeScript 声明。React 为 peer，ECharts 为运行依赖；复用既有固定版本，不引入新工具栈。根检查真实覆盖新包构建、静态、类型与测试，开发命令先构建依赖再监听。
2. 将现有注册表与文字/矩形/柱状图绘制迁入播放器包，由编辑器与只读播放器共同消费。原子节点创建工厂留在编辑器；播放器不包含命令执行、历史管理、属性表单、拖动、选择或应用 UI 组件。
3. 公开 `ScenePlayer` 接收场景文档，先复用共享运行时校验，再绘制独立校验产物；非法输入显示固定错误，不保留上一份画面。低层 `SceneView` 供持有合法文档的编辑器使用，注册能力只接受受信任的源码。共享文档协议继续不依赖 React。
4. `@neobo/scene/document` 提供文档及校验的独立公开入口，播放器只读取文档能力。通过独立消费者的生产构建检查实际模块图，拒绝编辑器、命令/历史及应用 UI 进入播放器运行入口，不用体积阈值代替边界验证。
5. 编辑器“预览”读取当前已提交文档的独立副本，隐藏编辑器并挂载播放器；返回编辑保留文档、选区和历史，不新增修订。拖动时禁用预览；视图离开时关闭菜单、取消拖动并卸载隐藏场景的绘制资源。只读视图不提供编辑事件或快捷键。
6. 本轮交付可嵌入的静态播放器及本地预览，不新增独立托管站点、跨窗口传输、存储、发布协议、身份权限、数据查询、动画或全屏 API。未来发布播放器必须消费固定且已授权的发布快照，不能把本地预览当作发布。

## 验证

复用既有绘制和资源回归，补充非法输入、文档替换、预览返回及资源释放；本地 Chromium 验证真实布局、图表和只读交互。独立消费者构建验证公共出口和模块边界；CI 保留基础检查，不增加浏览器安装或运行。

## 官方依据与兼容性

- 非打包的库使用 TypeScript NodeNext 与明确的 `.js` 相对导入，避免声明或 ESM 仅在源码别名下可用；实际验证原生 Node 与 Vite 消费编译产物。[TypeScript 库编译指南](https://www.typescriptlang.org/docs/handbook/modules/guides/choosing-compiler-options.html)。
- 根递归构建沿用 pnpm 默认依赖拓扑顺序，不启用绕过顺序的 parallel。[pnpm 递归命令](https://pnpm.io/cli/recursive)。
- 独立消费者使用 Vite 官方程序化构建和 `write: false`，通过构建插件读取真实模块与产物引用；不搜索压缩后的业务字符串，不落盘输出。[Vite JavaScript API](https://vite.dev/guide/api-javascript#build)、[构建输出配置](https://vite.dev/config/build-options#build-write)。

场景 schema、组件版本、命令和旧文档保持兼容。注册和绘制消费方迁移至 `@neobo/player` 公共出口，旧 Web 场景目录已删除；React、ECharts、Vite 等沿用既有固定版本，没有新增供应商依赖或发布工作流。实际检查证据见 [迭代 0016](../iterations/0016-readonly-player.md)。
