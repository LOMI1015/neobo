# ADR 0005：二维画布与可视操作规划

- 状态：已接受（实施及验证见迭代记录）
- 日期：2026-10-23
- 范围：文字/矩形绘制、选择与拖动、组合/拆组、浏览器验证
- 关联：[ADR 0003](0003-scene-contract.md)、[ADR 0004](0004-scene-commands.md)

## 背景

共享契约和统一命令已具备，需要通过实际画布验证可撤销的人工编辑。当前没有场景保存、身份或发布用例；本次不提前添加生产写入接口。

用户确认不连续的同级元素也可以组合，新组合占最上方选中元素所在层；组合内部保持原顺序，未选中图层彼此顺序不变。这会改变部分选中与未选中元素的遮挡关系，不能同时承诺原有全部遮挡关系保持。

## 决策

1. 在现有 Web 应用增加本地二维编辑器，默认进入空白 1920×1080 场景。服务检查视图保留，切换不丢当前编辑，但隐藏编辑器时取消拖动。画布无需 API 连接，界面明确提示当前会话不会在刷新后保存。
2. 提供文字/矩形添加、画布及图层选择、Shift 多选、属性应用、隐藏/显示、删除、组合/拆组及撤销/重做。文档变更统一提交既有历史；选择、表单草稿和拖动预览不写入文档。
3. 使用原生 SVG、Pointer Events 和 React，不增加生产渲染或状态依赖。只读 `SceneView` 不引用编辑器，外部 SVG 持有 viewBox、选择轮廓和事件；按 `rootIds`/`children` 顺序绘制，隐藏父节点时整个子树不绘制。
4. 节点采用 `translate(x y) rotate(angle width/2 height/2)`。组合宽高定义边界和旋转中心，不缩放、自动布局或裁剪子元素；属性区明确这一限制。文字用 `foreignObject` 内原生 HTML 保留换行并自动折行，自身边界裁剪；只传 React 文本子节点，不执行输入标记。
5. 共享包增加实际消费所需的世界四角、世界方向平移、组合及拆组规划。只使用刚性变换所需的 sin/cos，不建设通用矩阵引擎；规划复用文档校验，由既有执行器预验，再交给历史提交。
6. 屏幕指针经根 SVG 的 `getScreenCTM().inverse()` 转成场景坐标，平移再逆父世界旋转得到局部位移。不可逆或非有限坐标明确失败；被选中祖先覆盖的后代只移动一次。
7. 一次拖动只在 pointerup 提交一批，零位移不创建历史。预览是独立文档，保留起始修订号；拖动时其他编辑禁用。取消、失去捕获、Escape、窗口失焦、视图隐藏及卸载均释放捕获，不消耗修订；监听随生命周期释放。
8. 组合以共同父坐标中的选中节点旋转边界建立零旋转新组，按原顺序移入并补偿位置。拆组组合父子刚性变换，恢复位置、角度和原位置处的子节点顺序；隐藏组合拆开时直接子节点保持隐藏。超出坐标、尺寸、结构或命令上限时整体拒绝，不裁剪数值或静默分批。
9. 组合至少两个同级节点，组合/拆组最多 49 个直接目标，遵守既有每批 100 项命令上限；空组合可以拆除。保留修订号耗尽的真实错误码；修订冲突后同步最新内存文档，再提示重新操作。
10. 增加固定版本 Playwright 1.64.1 的 Chromium 回归，与 jsdom 结构/交互测试分开。按维护者确认，浏览器安装和回归放在本地验收，画布交互或渲染变更时在提交前运行并记录 PR 结果；CI 保留构建、类型、静态、单元/集成测试、配置与安全检查。服务与浏览器由测试工具创建、隔离和关闭，测试失败明确退出。

## 复用依据

- SVG 的 viewBox、嵌套坐标和公开屏幕矩阵提供实际坐标转换；Pointer Events 捕获用于画布外完成或取消拖动。[SVG2 坐标](https://www.w3.org/TR/SVG2/coords.html)、[SVG 图形接口](https://www.w3.org/TR/SVG2/types.html#InterfaceSVGGraphicsElement)、[Pointer Events3](https://www.w3.org/TR/pointerevents3/)。
- 复用 React 状态和副作用清理，不将业务状态放入渲染对象，也不自造订阅框架。[React Effect](https://react.dev/reference/react/useEffect)。
- Playwright 1.64.1 为 Apache-2.0，要求 Node.js ≥20，兼容仓库 Node.js 24；仅作为开发依赖，通过锁文件固定。[官方发行记录](https://playwright.dev/docs/release-notes)、[许可证](https://github.com/microsoft/playwright/blob/v1.64.1/LICENSE)、[服务生命周期](https://playwright.dev/docs/test-webserver)。

## 范围与后续

本次不包含平移/缩放工具、框选/吸附、拖动尺寸手柄、组件注册器、完整播放器、存储、权限、主题、图表、三维、动画或 AI 调用。旋转和尺寸通过属性表单应用；窄屏浏览器验证不等于真机触控验证。

下一步推进组件注册与图表渲染验证，随后继续编辑器/播放器打包、主题及三维。性能预算仍需目标硬件、分辨率与长时间场景测量，不用本次测试时长代替性能数据。
