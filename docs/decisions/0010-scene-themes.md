# ADR 0010：两套场景主题与可撤销切换

- 状态：已接受（实施与本地验收通过）
- 日期：2026-10-23
- 范围：主题契约与预设、场景命令、编辑/播放统一绘制
- 关联：[ADR 0003](0003-scene-contract.md)、[ADR 0008](0008-static-bar-chart.md)、[ADR 0009](0009-readonly-player.md)

## 背景

用户确认先提供“中性浅色”和“深色蓝”两个固定场景主题，覆盖画布背景、文字颜色、矩形填充/描边及柱图配色，支持切换、撤销和预览一致。现有颜色散落在播放器和 Web 画布宿主，文档没有主题引用；主题不能只存在于编辑器状态或依赖应用全局 CSS。

## 决策

1. 新增框架无关的 `@neobo/theme` 包，复用既有 Zod 和 TypeScript 工具。两个固定主题定义包含标识、版本、名称与有界实色 token，分别覆盖背景、文字、矩形填充/描边、柱、图表文字、轴线和网格；定义在运行时严格校验，公开预设为独立冻结数据。当前不加载远程主题或执行主题代码，不提供逐元素固定覆盖、自选色、字体尺寸、素材或动画配置。
2. 场景文档增加可选 `theme: { id, version }`，只接受内置 `neutral-light` / `deep-blue` 的版本 `1`。旧 Scene v1 文档缺省时按既有中性浅色绘制，解析不偷偷注入字段；显式主题进入文档及快照。旧文档继续接受，旧读取器会拒绝带新增字段的文档，不宣称前向兼容或已实现迁移。节点类型、组件版本与布局/数据保持不变。
3. 新增 `scene.theme.set` 操作，通过既有严格命令、修订检查及原子批次提交；撤销和重做复用文档历史。编辑器点选当前有效主题不执行命令，不增加修订。未知主题/版本和非法字段明确拒绝，失败不改变场景或历史。
4. 播放器从共享定义解析有效主题，通过内部上下文传给内置绘制；公共注册回调接口保持兼容。共享 `SceneView` 首先绘制画布背景，使编辑器、预览与独立嵌入一致；不改变元素顺序和变换。应用 UI 继续使用已有设计变量，场景主题与应用控件风格分开。
5. 柱图以既有有类型的 setOption 适配 token，主题变化也纳入绘制去重和错误恢复条件；复用当前实例，不因换色重新初始化或 resize。懒加载、等值副本不重复更新及隐藏/卸载释放行为保持，实际文字、坐标轴、网格与柱都需验收。
6. 主题入口复用右键菜单和“更多操作”的自定义单选子菜单，支持空白场景和键盘访问，拖动时禁止切换。切换及仅主题的撤销/重做保留选区和节点属性草稿；真实节点修改仍按既有规则刷新草稿。预览读取当前提交文档中的主题。

## 验证

共享层覆盖旧文档、非法引用/版本、原子失败、修订冲突与撤销重做；播放器覆盖配色、实例复用、失败恢复及独立构建边界；编辑器覆盖菜单、草稿/选区保留、预览一致与同值不提交。本地 Chromium 验收两套主题实际 SVG 和横屏/窄屏，CI 不增加浏览器安装或执行。实现检查完成后更新对应说明与迭代记录。

## 官方依据与验收

React Context 传递同一场景的稳定主题 token，公开注册回调继续返回独立组件，不在普通回调内调用 Hook。[React Context](https://react.dev/reference/react/createContext)。属性表单按已提交节点值变化更新自身状态并使用 key 重置子表单，主题修订不触发表单重挂载；采用 React 支持的受条件保护的当前组件状态调整模式。[官方状态调整说明](https://react.dev/reference/react/useState#storing-information-from-previous-renders)。

ECharts 6 支持运行时主题切换，本轮只涉及已有静态配置中的八个实色 token，因此沿用有类型的 setOption 适配，不维护第二套 ECharts 注册主题或重建实例。[ECharts 6 官方说明](https://echarts.apache.org/handbook/en/basics/release-note/v6-feature/)。实际生产模块图继续验证无编辑链和 ECharts 懒加载。

构建、类型、静态、API/核心/组件测试、真实 Chromium 与启动退出均已验证，完整证据见 [迭代 0017](../iterations/0017-scene-themes.md)。
