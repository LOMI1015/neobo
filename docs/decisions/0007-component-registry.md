# ADR 0007：现有原子组件的 Web 注册入口

- 状态：已接受（实施及验证见迭代记录）
- 日期：2026-10-23
- 范围：文字/矩形的元数据、默认创建与只读绘制
- 关联：[ADR 0003](0003-scene-contract.md)、[ADR 0005](0005-canvas-editor.md)、[模块说明](../../apps/web/src/scene/README.md)

## 背景

二维画布与统一应用 UI 已完成，文字和矩形的默认值、类型名称、绘制逻辑仍散落在编辑器与 `SceneView`。路线图下一步需要组件注册；首个图表及其数据范围尚未确定，先统一已有原子类型的真实消费入口。

## 决策

1. 在 Web 的 `src/scene` 建立受信任源码注册入口，描述现有 `text`、`rectangle` 的组件版本 `1`、名称、默认尺寸、文字默认内容及纯绘制回调。组合继续是结构节点，不登记为原子组件。暂不引入依赖、共享业务包、通用属性字典、插件下载或动态代码执行。
2. 按类型和版本精确解析；重复、非法默认值、未知类型或版本明确失败，不自动覆盖、版本回退或绘制空白。默认值复用 `@neobo/scene` 的运行时校验，登记元数据保存为独立冻结快照。
3. 默认工厂按声明创建节点，保留原有画布内尺寸限制、居中、可见性、旋转和文字行为；再次经过共享契约校验，返回独立对象。编辑器仍通过既有 `node.add`、修订检查和历史提交，不把文档状态放进注册表。
4. `SceneView` 消费内置或调用方传入的注册表。它继续负责组合、引用顺序、隐藏子树及局部变换；原子回调只负责局部内容。通过替代现有矩形绘制验证注入入口，不以新增未确认的数据类型证明可扩展性。
5. `render` 为纯回调；含 Hook 或资源的实现返回独立 React 组件，由 React 管理其生命周期。清理覆盖隐藏、卸载及 StrictMode；不得在条件执行的普通回调内直接调用 Hook。[官方组件调用规则](https://react.dev/reference/rules/react-calls-components-and-hooks)、[Effect 清理](https://react.dev/reference/react/useEffect)。

## 影响与边界

共享场景 schema、组件版本、旧文档、API 校验和命令协议均保持兼容。注册回调依赖 React，因此实现位于 Web；共享契约继续保持框架无关。此入口复用现有类型，并未完成任意自定义组件协议、数据源、事件、主题、发布快照或独立播放器。

新增图表时必须先确认业务字段，并同时扩展严格数据契约、命令、编辑入口及回归证据；不能通过注册表绕过共享校验。真实浏览器验收保留在本地，CI 不增加浏览器安装或执行。
