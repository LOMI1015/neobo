# 路线图

状态日期：2026-10-23。这里只记录目标；完成情况以 [迭代记录](iterations/README.md) 为准。阶段按验收推进，暂不承诺日期和未经测量的性能指标。

当前已具备本地前后端与独立数据库环境、API 请求日志基础，以及接入统一命令的二维画布：文字/矩形/静态单系列柱状图绘制、选择、拖动、属性编辑、组合/拆组和撤销/重做。应用 UI 已接入 shadcn/ui 与统一设计变量，提供画布/图层右键编辑菜单；原子组件的类型名称、默认值和只读绘制已统一到 [独立播放器包](../packages/player/README.md)，节点创建及命令保留在编辑器。柱状图支持手填分类/数值、完整数据替换和生命周期清理，尚未连接数据源。内容仅在当前会话内，已提供本地 Chromium 回归；CI 保留基础质量门禁。只读播放器已独立打包并验证不携带编辑代码，编辑器支持提交态预览与无损返回。下一步推进主题接口与两个小型验证包，具体表现及首批可配置字段需在实现前确认，再继续三维与动画；存储、权限、动态数据和 AI 创作仍属于后续目标。

## 0. 开发基线

- 架构、AI 阅读入口、开发规范和迭代记录。
- 日志与审计设计；明确复用、事实查证、简洁注释和不确定事项确认规则。
- 真实可运行的格式、文档链接、工作流及检查工具验证。
- 新业务包必须接入静态检查、类型检查、测试和构建。
- GitHub 保护规则与发布约束可按文档配置；远端设置需维护者实际启用。

验收：干净环境使用锁文件安装后，`pnpm check` 通过；工作流通过 actionlint；不存在虚构的应用启动或业务测试。

## 1. 场景与渲染验证

- 建立前后端应用与轻量共享契约，落地 NestJS + Fastify 的实际请求校验。
- 优先落地 [请求日志基础](logging.md#8-落地顺序与验收)：统一 Pino、服务端请求标识、错误边界、脱敏和并发隔离。
- 场景版本、原子元素、组合、统一命令、撤销/重做。
- 同一画布的二维图表、三维模型、跟随标签、基础动画与时间轴。
- 极简底座、主题包接口和两个风格不同的小型验证包。
- 编辑器与只读播放器独立打包（已完成）；已有矩形表现替换验证公开注册入口，任意新类型仍需明确契约。
- 发布快照加载、数据访问、动画与场景交互随对应平台能力推进。

验收：同一场景切换主题保留布局、数据绑定和交互；鼠标与命令更新一致；记录 1080p/4K、目标硬件和长时间运行结果，据此制定性能预算。

## 2. 数据与基础平台

- PostgreSQL、MySQL、HTTP JSON 连接器和受控查询。
- 配置刷新、超时、重试、查询复用及权限缓存隔离。
- 用户、项目、角色、行/字段过滤、导出权限及审计。
- 审计追加表、同事务写入、独立查询权限与故障策略，不用运行日志代替审计。
- 草稿、发布快照、素材、可信扩展和兼容性管理。
- 基础平台阶段后半段补充 CSV/Excel 导入。

验收：先过滤再汇总；AI/图表/导出复用同一授权入口；草稿修改不影响已发布版本，旧快照及资源可恢复。

## 3. AI 创作闭环

- 多模型配置、能力检测、自定义接口地址和本地模型服务适配。
- 对话创建场景、选择元素后的局部修改、主题效果调用。
- 操作校验、修订号冲突、取消、超时与失败保护。
- Agent / Worker 关联日志、重试与取消、供应商实际用量；默认不记录模型正文。
- 以供应商模拟和固定样例验证授权、正确性、耗时与调用成本。

验收：连接数据 → 对话搭建 → 拖拽组合 → 添加三维和动画 → 换主题 → 按权限发布；失败不会破坏已有场景。

## 4. 首个正式版本

- 确定许可证、支持环境和版本号，完善迁移与备份说明。
- 交付可复现构建、容器与 Docker Compose，自托管安装文档。
- 确认日志和审计的保存周期与容量，落实轮转、清理和告警，验证存储故障及日志性能开销。
- 按 [CI/CD 规则](ci-cd.md) 建立有审批的制品发布，验证健康检查与回滚。

验收：从干净环境部署；使用固定版本制品；发布证据可追溯，数据兼容和回退路径明确。

多人实时协作、通用三维建模、不可信代码沙箱和扩展市场在后续路线中单独评估。
