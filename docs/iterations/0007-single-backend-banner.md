# 0007：修复后端艺术字重复输出

- 日期：2026-10-23（Asia/Shanghai）
- 状态：已完成（根因已复现，修复和本地检查通过）。
- 用户要求：艺术字只由后端输出一次。

## 目标

修复开发环境首次启动时后端意外重启，避免同一次启动看到两次艺术字；外层启动器不额外打印品牌标题。

## 原因与实际变化

- 艺术字只在后端一处调用，前端没有打印。原命令先完整编译，再并发启动编译监听和 Node 监听；编译监听首次重新写入产物，触发 Node 二次启动。
- API 开发命令先 `tsc --build --force`，再进入 `tsc --build --watch`，复用同一构建状态；强制首编译也覆盖产物被删除但缓存仍存在的情况。普通构建命令保持原样。
- 根启动器删除额外的 neobo 版本标题，只显示通用启动提示和模块标签；艺术字仍由后端监听成功后的唯一入口输出。
- 源码修改后的正常重启仍可打印艺术字，不通过全局开关掩盖启动问题，不增加依赖。
