# 0003：中文 PR 模板与 AI 提交流程

- 日期：2026-10-23（Asia/Shanghai）
- 状态：已完成（本地检查通过，远端 CI 待验证）。

## 目标

让 AI Agent 完成已授权任务后，按统一模板直接提交中文合并请求；GitHub 中使用 PR，对应日常所说的 MR。

## 实际变化

- 默认 PR 模板明确问题与结果、实现要点、验证、影响与回退四项。
- 新增中文标题和正文规则、AI 暂存与提交流程、GitHub CLI 正文文件用法；同步 AI 入口和贡献规范。
- CI 在 PR 事件中读取事件 JSON，检查 Conventional Commits 标题、中文描述与实际中文正文；标题或正文编辑后重新执行。
- 排除模板标题、注释、代码、网址和勾选清单，防止未填写模板被当作中文说明；新增工具回归测试，接入统一检查。
- 单人维护继续保留 PR、`quality` 和 0 人批准，由维护者自审并手动合并。

| PR 事件预检       | 通过：`pnpm check:pr <事件文件>` 接受中文标题与已填写正文，拦截未填写的默认模板、纯英文标题，以及中文小标题配英文正文 |

## 遗留问题

- 模板需合入默认分支后，GitHub 页面新建 PR 才会自动使用；远端 CI 尚未验证。
- 中文检查只能识别常见漏填与纯英文内容，说明质量和事实仍需评审。机器人 PR 也需遵守中文规则。
