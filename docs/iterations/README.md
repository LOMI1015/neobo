## 新增记录

复制 [模板](TEMPLATE.md)，命名为 `NNNN-short-name.md`，并在上表顶部增加入口。编号连续，标题说明实际交付结果。

每条记录应包含：日期、目标、实际变化、验证命令及结果、遗留问题和下一步。可以附关联 PR 或提交，不编造尚不存在的链接与提交号。

## 维护规则

- 已完成内容写记录，未完成目标更新 [路线图](../roadmap.md)。
- 重要架构取舍另建 ADR，并从记录引用；不能只藏在聊天或日志中。
- 区分已实现、仅配置、待验证与受环境限制的事项。
- 验证写明命令及实际结果。涉及性能时记录硬件、场景和规模；远端 CI 尚未运行就明确标注。
- 原有记录保留历史。纠正错误时补充说明，不把早期完成状态改造成后续成果。
- 记录不包含凭据、真实敏感数据、完整模型对话或临时调试输出。
