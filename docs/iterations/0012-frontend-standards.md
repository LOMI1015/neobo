# 0012：前端视觉与交互开发规范

- 日期：2026-10-23（Asia/Shanghai）
- 状态：已完成（规范与调研，未实施组件库接入）

## 目标

补充统一前端视觉、精简页面文字及自定义编辑菜单的开发规范，并核对 shadcn/ui 是否适合作为组件方案。

## 实际变化

- 在开发规范中规定应用 UI 统一管理颜色、字体、圆角、间距及交互状态，明确与用户场景内容、场景主题包的边界。
- 禁止用途和功能讲解等说明文案，详细解释放入文档；保留简短标签、状态、必要风险及错误反馈和可访问名称。
- 编辑操作优先使用公共自定义右键菜单，保留键盘与触屏入口；菜单、弹框等禁止使用浏览器原生交互，复用成熟组件能力及既有场景命令。
- AI 开发入口同步三条约束；核对 shadcn/ui 官方介绍、Vite 接入、主题变量、右键菜单及 MIT 许可证，记录推荐与接入注意事项。
