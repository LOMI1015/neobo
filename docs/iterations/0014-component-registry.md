# 0014：原子组件注册与文档维护

- 日期：2026-10-23（Asia/Shanghai）
- 状态：已完成（并行开发、统一 review、本地验收与文档检查通过）

## 目标

按实际开发进度清理过时说明，明确每次开发或修改完成检查后先同步文档、再提交 PR；继续路线图中不依赖图表范围选择的原子组件注册。

## 实际变化

- 更新 README、架构、本地开发、日志与 CI 说明，移除“仅有骨架”、Zustand 已在使用、CI 从未验证等失效表述，区分当前能力和完整目标。修正 shadcn/ui 的 MIT 许可与本仓库整体许可证待定的边界。
- 在 AI 入口、开发规范、贡献与 PR 流程中统一交付顺序：实现/review/检查 → 按最终结果更新文档和迭代 → 文档格式/链接检查 → 暂存核对、提交、推送及 PR。历史迭代保留原始证据，失效 ADR 条款补后续决定链接。
- 新增 Web 注册入口，集中登记现有文字、矩形第一版的名称、默认尺寸、默认文字与绘制回调；编辑器创建、图层/属性名称和只读绘制真实消费登记内容。
- 注册按类型与版本精确解析，重复、非法默认值及未知版本明确失败。元数据保存独立冻结快照，工厂返回独立节点并复用共享校验，再交既有命令与历史提交。
- `SceneView` 可注入显式注册表替代现有类型绘制，组合、隐藏和几何语义继续由场景掌握。资源由回调返回的独立 React 组件管理，并有 StrictMode、隐藏和卸载回归。
- 清理共享包 README 中“视觉分组/拆组待实现”等旧说明，增加注册入口示例及维护边界；共享 Scene v1、API、命令协议、依赖和 CI 工作流均未改变。

## 遗留问题

- 注册入口仅支持现有文字/矩形版本，不提供任意组件数据结构、动态插件或不可信代码执行；React 绘制仍在 Web，未建立独立播放器包。
- 首个图表及业务数据范围尚未明确，因此本轮没有安装 ECharts 或新增图表协议；不把建议当成确认。
- 场景仍仅在当前会话，存储、权限、主题、三维、动画及 AI 仍待实现。
